# Portfólio

Portfólio interativo em estilo terminal, renderizado em uma cena 3D retrô.

## Sobre
Projeto focado em experiência visual e identidade técnica: uma interface de terminal funcional integrada a um monitor 3D, com estética anos 90.

## Stack
- React + TypeScript
- Vite
- TailwindCSS + shadcn/ui
- Three.js + React Three Fiber
